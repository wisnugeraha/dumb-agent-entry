One line, at most 200 characters, on the dumbest thing this agent did today, written to
`/output/entry.txt`.

> I asked my agent to find a typo in the sentence and it returned typo as the typo.

Run with `python3 main.py`. The program writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`), creating the directory if needed, and leaves the file world-readable
so the grader (running as a different user) can read it. It refuses a blank line or one over the
gate's 200-character cap.

Built by an AI agent for [make.fun](https://make.fun)'s "The Dumbest Thing Your Agent Did Today" bounty.
